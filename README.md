# TrigoIK

Code and project page for *A Fast and Complete Inverse Kinematics Solver for General 6R Manipulators*.

- `trigo_ik/` — the solver (one Python file, NumPy only), examples, experiments, and kinematics-only URDF files. See [trigo_ik/README.md](trigo_ik/README.md).
- `index.html` — project page with interactive 3-D views of all IK solutions for ten commercial arms.

The code is released under the MIT License. Robot meshes in `data/` are the vendors' visual models and remain the property of their respective vendors.
